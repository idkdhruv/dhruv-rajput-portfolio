# Dhruv Rajput — Portfolio

A responsive, static personal portfolio built with HTML, CSS, and vanilla JavaScript. The site uses a charcoal-and-gold visual system, compact project cards, an academic timeline, research, activities, and contact links.

## Files

- `index.html` — page content and navigation
- `assets/style.css` — responsive styling
- `assets/script.js` — navigation state and unavailable-link notices
- `vercel.json` — static deployment configuration

## Missing links

Links not supplied yet are clearly marked **Unavailable**. Add the real URL in `index.html` when it is available.

## Deployment

The site is static and has no build step or backend. Deploy the repository root with Vercel using the **Other** framework preset and no build command. GitHub Pages can serve the root `index.html` directly.
